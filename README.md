# 一页通 · 长者紧急贴纸

> **ICE (In Case of Emergency) stickers for Chinese-speaking seniors.**
> A small sticker on the back of a senior's phone says "I speak Chinese, limited English" and shows an emergency contact number. Scanning its QR code opens a bilingual page with key medical info and one-tap buttons to call family. No app, no account, no server-side data.

很多华人长者英文有限。遇到摔倒、走失或突发疾病时，路人和急救人员不懂中文，长者也说不清自己的病史；手机有密码锁，别人也找不到家人的电话。

一页通是一张贴在手机背面的紧急贴纸：

- **表面**：用英文写明"我说中文，英文有限"，并印上一个紧急联系电话（ICE）
- **二维码**：任何人用手机相机一扫，就能看到长者的关键医疗信息（英文为主，附长者的语言：中文或西班牙语），并一键拨打家属、日间保健中心或 911

整套工具免费、不用下载 App、不用注册，也**不在任何服务器上存储个人资料**。

---

## 怎么做到不存资料

资料不存在服务器上，而是直接写在二维码的网址里：

```
HTTPS://NOLAN11701.GITHUB.IO/ice/#1*WANG-LI*...*D6265550101MEI
└──────── 所有人共用的空白网页 ───────┘└─────── 这位长者的资料 ──────┘
```

浏览器打开网址时，只会向服务器请求 `#` 前面的部分，`#` 后面的内容不会发出去。页面加载后，再由手机上的 JavaScript 读取 `#` 后面的资料并显示出来。

所以网站只是一个静态网页（托管在 GitHub Pages），没有后端、没有数据库、没有月费，也没有资料可以泄露。

> 上面例子里的姓名和电话都是虚构的，本文档和工具里的示例资料都使用 555-01xx 虚构号段。

## 现场使用

### 准备

- 平板电脑（打开贴纸工具）
- 激光打印机和 Avery 94230 防水标签纸（见下面的"打印"）
- 纸质双语同意书：设置前请长者或家属签名，说明会记录哪些资料、资料存在哪里

### 流程

1. 打开入口页，进入**贴纸工具**
2. 选模板：**普通话**、**粤语**、**英语**或**西班牙语**。之后录入的每个人都会套用这个模板的语言设定
3. **快速添加**：输入英文名、中文名、称呼、ICE 电话，按 **Enter** 加入，光标会回到名字栏，直接录下一位
   - 只有英文名是必填的，可以先只录名字；名单里会标"⚠ 缺电话"，补上后才能打印
   - 人数不限，可以提前把一大批长者都录进去
4. 在名单里点一个人，右边可以补充病史、过敏、用药，并看到**实际大小的贴纸**和**扫码后的页面**。请和长者或家属一起核对
5. 需要不止一张的（例如两部手机、多留一张备用），在名单里改 **份数**，默认 1
6. 点 **打印待打印**：所有还没打印、资料完整的人按份数排版，每 10 张贴纸一张标签纸
7. 打印成功后，在预览里点 **标记为已打印**，这些人会显示"✓ 已打印"
   - 已打印的人如果资料又改了，会自动变回待打印；也可以点 **重印** 手动改回
8. 贴好、确认无误后，点 **清空已打印**；**全部清空** 会连还没打印的一起清掉

工具里的"加入示例"按钮会加入几位虚构的长者，用来现场演示或培训志愿者。

### 要记录的资料

| 项目 | 说明 |
|---|---|
| 英文 / 拼音姓名 | 必填 |
| 中文姓名 | 选填，可以选择是否放进二维码（放进去二维码会密一些） |
| 语言 | 普通话 / 粤语 / 英语 / 西班牙语，决定贴纸上的提示语和求助页的第二语言 |
| 病史 / 急救要点 | 从清单勾选，最多 3 项，可以另加一项英文 |
| 过敏 | 从清单勾选，最多 2 项，可以另加一项英文 |
| 用药 | 英文药名，最多 3 种 |
| 联系人 | 最多 2 位：称呼、英文名（选填）、电话。第 1 位的电话印在贴纸表面 |

数量有上限，是为了让二维码保持稀疏、容易扫。

**不要记录**：社会安全号码、Medi-Cal / Medicare 卡号全号、住址。

## 贴纸

### 表面内容

从上到下：

1. 红色标题 **EMERGENCY**
2. 按长者的语言写提示语（见下表）
3. 二维码，下面写 "Scan for medical & family info"
4. 日间保健中心简称，深蓝色窄体加粗一行：**Crown City ADHC Center**（不印中心电话）
5. **EMERGENCY CONTACT · ICE** 和第 1 位联系人的电话

| 语言 | 贴纸提示语 | 求助页的第二语言 |
|---|---|---|
| 普通话 | I speak Chinese. Limited English. | 中文 |
| 粤语 | I speak Cantonese. Limited English. | 中文 |
| 西班牙语 | I speak Spanish. Limited English. | 西班牙语 |
| 英语 | In an emergency, please help. | 无（只有英文） |

求助页另外会显示中心的完整名称、地址、电话和"Call day center"按钮。中心信息写在 `shared.js` 的 `CENTER` 里，不放进二维码，所以不会让二维码变密。

姓名、病史等隐私资料只在二维码里，不印在表面。二维码扫不出来时（贴纸磨损、扫码的人没有网络），路人仍然可以直接拨打表面的 ICE 电话。

贴纸提示用**手机相机**扫码。微信扫一扫打开外部网页的效果不稳定，不建议使用。

### 尺寸

**1.5″ × 2.75″（38 × 70 mm）**，竖着贴在手机背面、摄像头下方。

- 常见手机背面平整的区域约宽 60 mm，小屏 iPhone 约 55 mm，38 mm 宽在常见手机上都贴得下
- 二维码约 30 mm，按目前的资料量，每格约 0.53–0.73 mm，普通激光打印机印出来就能扫

## 打印

### 标签纸

| 项目 | 规格 |
|---|---|
| 型号 | **Avery Presta 94230**（Printable Durable White Rectangle Labels） |
| 尺寸 | 1.5″ × 2.75″，US Letter 纸每张 **10 个**（2 列 × 5 行） |
| 材质 | 防水白色薄膜，耐撕、耐油、耐冷热，泡水不坏 |
| 打印机 | **激光打印机**，或使用颜料墨水的喷墨打印机（染料墨水遇水会糊） |
| 购买 | [Amazon](https://www.amazon.com/dp/B08KJNNJJ6) |

不建议用热敏标签机：分辨率较低、只能打黑色，而且受热会褪色。

### 打印设置

- 缩放选 **实际大小 / 100%**，不要选"适合页面"
- 页边距选 **无**
- 默认二维码纠错等级为 Q，约 25% 被磨损或弄脏时仍能识别

### 第一次用新打印机或新纸时

1. 打开**打印测试页**，用普通纸打印（会印出标签轮廓）
2. 用尺量页面上的 50 mm 校准线，确认尺寸正确
3. 把这张纸叠在标签纸上，对着光看是否对齐；有偏差就在打印预览里调整 X / Y 偏移（mm）
4. 再用标签纸打印测试页，用不同的手机逐张扫码，确认都能扫出

标签之间的列距和行距是根据 Avery 规格推算的，正式使用前请用实物核对一次。

## 隐私与安全

- 资料只在平板浏览器的内存里处理，不上传、不保存；刷新或关闭页面就清空
- 网站不使用数据库，也不收集任何访问资料
- 求助页不加载任何外部文件，也不让搜索引擎收录
- 任何扫到二维码的人都能看到里面的资料，这和手机锁屏上的"医疗急救卡"类似。扫过码的人，浏览器历史记录里会留下这个网址，请在同意书中说明
- 这是**沟通辅助工具，不是医疗设备**，也不提供医疗建议

## 开发

### 文件结构

```
docs/                 GitHub Pages 从 main 分支的 /docs 发布
├── index.html        求助页；网址不带资料时显示为入口页
├── shared.js         共用：网址、代码表、资料编码和解码、求助页内容
├── shared.css        共用：求助页样式
└── tool/index.html   贴纸工具：录入、预览、打印、打印测试页（?sheet）
```

没有构建步骤，也没有依赖安装。贴纸工具从 cdnjs 加载 `qrcode-generator@1.4.4` 来生成二维码，从 Google Fonts 加载窄体字 Roboto Condensed（贴纸上的中心名称用）；打印按钮会等字体下载完才打开打印对话框。

### 本地预览

在仓库根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://localhost:8000/docs/tool/`。

本地生成的二维码仍然指向线上网址；想在电脑上看扫码后的效果，可以在工具里展开"扫码后看到的页面"。

### 二维码资料格式（v1）

`#` 后面的资料由 8 个字段组成，用 `*` 分隔：

| # | 内容 | 例子 |
|---|---|---|
| 1 | 格式版本 | `1` |
| 2 | 英文名，空格写成 `-` | `WANG-LI` |
| 3 | 中文名，UTF-8 百分号编码，可为空 | `%E7%8E%8B%E4%B8%BD` |
| 4 | 语言：`M` 普通话 / `C` 粤语 / `E` 英语 / `S` 西班牙语 | `M` |
| 5 | 病史代码，用 `.` 分隔 | `HTN.DM` |
| 6 | 过敏代码 | `PCN` |
| 7 | 用药 | `METFORMIN.AMLODIPINE` |
| 8 | 联系人：称呼代码 + 10 位电话 + 英文名，用 `.` 分隔 | `D6265550101MEI` |

为了让二维码尽量稀疏：

- 病史和过敏只存代码（如 `HTN`），求助页再用 `shared.js` 里的对照表展开成中英文
- 资料部分只用 `0-9 A-Z % * - .`，网址的协议和域名写成大写，这样二维码可以用更紧凑的"字母数字模式"；路径 `ice/` 区分大小写，必须保持小写，这几个字符单独用字节模式
- 不压缩：对这么短的中文资料，压缩后反而更长

### 修改时要注意

已经印出去的贴纸无法收回，所以：

- **网址不能改**：`shared.js` 里的 `BASE_URL`、仓库名、Pages 设置都要保持不变
- **格式只能向后兼容**：新字段只能加在末尾；已有字段的含义不能改
- **代码只能新增**：病史、过敏、称呼、语言的代码一旦用过，就不能删除或改含义
- **翻译**：病史、过敏、称呼的西班牙语翻译写在 `shared.js` 的代码表里，正式使用前最好请会说西班牙语的人看一遍
- **改了共用文件要更新版本号**：页面引用 `shared.js` / `shared.css` 时带了 `?v=2`，修改后要把两个页面里的版本号都加 1，否则浏览器可能继续用旧的缓存
